待ち受け  / セッション 0

あとは Cloudflare 側の設定です。

  1. DNS の A レコードをこのマシンの IP に向け、プロキシ(オレンクラウド)を ON
  2. SSL/TLS モードを Flexible にする
  3. 80 番へは Cloudflare の IP 帯だけを通す(これがないと IP を隠せません)

ブリッジを使う人には「wss://あなたのドメイン」を伝えてください。
